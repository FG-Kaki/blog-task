[프로젝트 세부 사양서 및 기능 보완안: SpaceCleaner]

1. 시각화 및 UI/UX 개선안
 - 색상 알고리즘 보완:
   * 범주(Type) 색상과 방치 기간(Age)을 함께 표현하기 위해 '기본 색상(범주) + 명도/채도(방치 기간)' 조합 활용.
   * 예) 1년 이상 미사용된 파란색 파일 -> 빛바랜/어두운 파란색으로 표현.
 - 범례(Legend) 툴바 상시 제공: UI 상단/하단에 색상별 의미(적색:시스템, 파란색:일반, 주황색:구버전, 노란색:캐시) 및 색상 농도(방치 기간) 안내 바 배치.

2. 파일 분류 로직 구체화
 - 시스템 파일(적색): Windows 폴더, ProgramData 일부, bootmgr 등 규칙 기반 예외 리스트(White/Blacklist) 구성.
 - 구버전/레거시(주황색): WinSxS 일부 레거시, Windows.old, Installer 캐시 분석 알고리즘.
 - 캐시 파일(노란색):AppData\Local\Temp, ShaderCache, pip\cache, Chrome\User Data\Default\Cache 등 주요 경로 패턴 매칭.

3. 안전성 및 예외 처리 (Safety & Error Handling)
 - 권한 관리: 관리자 권한으로 실행하더라도 System/TrustedInstaller 권한 영역은 1차적으로 수정 불가하도록 보호.
 - 안전 삭제 경고창 레벨화:
   * Level 1 (일반 파일): 일반 확인 팝업
   * Level 2 (캐시/구버전): "삭제 후 다시 생성될 수 있습니다 / OS 업데이트 복구가 불가능할 수 있습니다" 안내
   * Level 3 (시스템 파일): 배경색 빨간색 경고창 + "CONFIRM" 문구 직접 입력 방식 적용하여 실수 방지.

4. 권장 기술 스택 및 기술 검토
 - UI/시각화: C# WPF (LiveCharts / custom Canvas Draw) 또는 C++ (Qt) / Electron + D3.js (성능 고려 시 Native 권장)
 - 파일 스캔 performance: OS의 USN Journaling 또는 Fast Directory Enumeration API 활용하여 스캔 속도 극대화.
